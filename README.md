# 🛡️ Interactive Cyber Threat Intelligence Dashboard

An interactive **Cyber Threat Intelligence (CTI) Dashboard** designed to visualize, explore, and monitor cyber threat activity through an intuitive security-focused interface.

🔗 **Live Demo:** https://interactive-cyber-threat-intelligence.netlify.app/

---

## 📊 Overview

The Interactive Cyber Threat Intelligence Dashboard provides a centralized interface for exploring cybersecurity threat data and identifying patterns across different types of attacks.

The dashboard combines interactive visualizations, threat statistics, malware information, geographic intelligence, and recent threat activity to provide a clear view of the cyber threat landscape.

---

## 🚀 Features

### 🌐 Interactive Cyber Threat Globe

Visualize cyber threat activity geographically using an interactive **3D Cyber Threat Globe**.

- Rotate and explore the globe
- Identify high attack-volume regions
- View threat activity by geographic origin
- Explore global threat patterns

### 📈 Threat Analytics

The dashboard provides high-level threat statistics including:

- Threats detected today
- Attack-type distribution
- Top threat origins
- Active malware detections
- Threat trends
- Resolved threats

### 🎯 Threat Filtering

Threats can be filtered by attack category, including:

- Phishing
- Ransomware
- DDoS
- Malware
- SQL Injection
- Brute Force

### 🦠 Malware Intelligence

The dashboard highlights active malware families and their detection activity.

Example malware information includes:

- Malware family
- Detection count
- Activity trends
- Threat classification

### 📊 Attack Distribution

Interactive charts provide a visual breakdown of cyber attack types and allow users to drill down into threat categories.

### 📅 Threat Trends

The dashboard provides historical threat trends, including:

- 30-day activity
- Peak threat levels
- Average daily threats
- Resolution rates
- Overall trend direction

### 🚨 Latest Threat Pulses

A continuously updated threat table displays recent activity using information such as:

| Threat | Type | Origin | Severity |
|--------|------|--------|----------|
| Threat activity | Attack type | Geographic origin | Severity level |

The dashboard is configured with automatic refresh functionality to keep the displayed information current.

---

## 🖥️ Dashboard Sections

The application contains several major sections:

- **Overview** — High-level cybersecurity statistics and visualizations
- **Threats** — Threat activity and attack intelligence
- **Malware** — Malware family and detection information
- **Reports** — Threat intelligence reporting
